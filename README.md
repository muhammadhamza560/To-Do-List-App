# 📝 To-Do List Application

A responsive task management web application built with HTML, CSS, and JavaScript to help users organise, manage, and track their daily tasks.

## 🌐 Live Demo

Open the live application: [Add Your GitHub Pages Live Link Here]

## ✨ Features

- Add new tasks
- View all saved tasks
- Edit existing tasks
- Delete tasks with confirmation
- Mark tasks as completed
- Reopen completed tasks
- Filter tasks by All, Pending, and Completed
- Automatic task summary (Total, Pending, Completed)
- Save tasks using browser Local Storage
- Restore tasks after refreshing or reopening the browser
- Responsive interface for desktop and mobile devices

## 🎯 Task Management

| **Action** | **Description** |
| -------------- | --------- |
| Add Task | Create a new task using the input field |
| View Tasks | Display all saved tasks |
| Edit Task | Update an existing task title |
| Delete Task | Remove a task from the list |
| Complete Task | Mark a task as completed |
| Reopen Task | Move a completed task back to pending |
| Filter Tasks | Display All, Pending, or Completed tasks |
| Task Summary | Display total, pending, and completed task counts |

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## 🚀 Run Locally

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Start adding and managing your daily tasks.

## 📚 Learning Objectives

This project demonstrates HTML page structuring, CSS styling, responsive web design, JavaScript DOM manipulation, event handling, arrays, functions, task filtering, CRUD operations, JSON data handling, and browser Local Storage.

## 🔒 Data Storage

- Tasks are stored locally in the user's browser.
- No backend or database server is required.
- Task data remains available after refreshing or reopening the browser.
- Data is not automatically synchronised across different devices or browsers.
